# 🌐 Portafolio Profesional | Mishell

¡Bienvenido/a al repositorio de mi sitio web personal! Este proyecto es un portafolio web responsivo e interactivo diseñado para presentar mi trayectoria profesional, experiencia laboral, formación académica y el conjunto de tecnologías que domino.

🔗 [Ver Portafolio en Vivo](https://mishfi20.github.io/Portafolio-Mishell-Figueroa/)

---

## 🚀 Sobre el Proyecto

Este sitio web actúa como una vitrina digital de mi perfil profesional. Fue diseñado con un enfoque prioritario en la experiencia de usuario (UX/UI), garantizando una navegación fluida, atractiva y completamente adaptada a cualquier dispositivo (móvil, tablet y escritorio).

### 📌 Secciones Principales:
* **Inicio:** Presentación de impacto y resumen rápido de mi perfil.
* **Acerca de mí:** Mi historia personal, motivaciones y enfoque de trabajo.
* **Habilidades:** Tecnologías, lenguajes de programación y herramientas aprendidas.
* **Experiencia Laboral:** Trayectoria profesional y roles anteriores..
* **Educación y Calificaciones:** Estudios académicos, certificaciones y formación continua.
* **Contacto:** Enlaces a mis redes profesionales.

---

## 🛠️ Tecnologías Utilizadas

El sitio fue desarrollado utilizando las tecnologías web fundamentales:

* **HTML5:** Estructuración semántica y accesible del contenido.
* **CSS3:** Diseños responsivos (Media Queries), animaciones, Flexbox y CSS Grid.
* **JavaScript (ES6+):** Dinamismo, interactividad de la interfaz y manejo del DOM.
